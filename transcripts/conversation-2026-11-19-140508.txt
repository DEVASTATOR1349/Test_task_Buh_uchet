● Фронт на React сделан. Сервис по-прежнему запускается одной командой, Node для
  этого не нужен:

  python -m advance_report

  Дальше открыть в браузере http://127.0.0.1:8000/?date=2026-11-10.

  Как выглядит. Строгий «банковский» минимализм:
  - тёплый светлый фон и один тёмно-зелёный акцент;
  - шрифт Inter для интерфейса, засечный Source Serif для даты и крупных сумм;
  - тёмная тема включается сама по настройке системы;
  - на телефоне таблица работ превращается в карточки.

  Что на странице:
  - Шапка: выбор даты и стрелки «±1 день». Так видно, как отчёт меняется после
    событий: 11.11 принята W-23, 12.11 появляется переплата 5 000 по D-2.
  - Сводка: крупно «Осталось оплатить» по всем договорам. Рядом выплачено, долг
    за принятые работы и сумма в очереди.
  - Договор: полоса оплаты (зачтено в работы, аванс, в очереди, остаток) и
    предупреждения. Ниже таблица работ с колонкой «Чем оплачено». При наведении
    на платёж подсвечиваются работы, которые он закрыл, — это прямой ответ
    бухгалтеру «за что мы рассчитались».
  - Итоги и список платежей по договору, у каждого платежа статус на выбранную
    дату.
  - Особые случаи: пока идёт загрузка, страница показывает заготовку. Если на
    дату нет договоров, так и пишет. Если в CSV ошибки, перечисляет их
    построчно.

  Как устроено:
  - Все суммы считает Python-сервер, фронт их только показывает. Сам он
    вычисляет лишь ширину полосы и «остаток минус очередь», в копейках через
    BigInt, без float.
  - Собранный фронт лежит в advance_report/static/ и закоммичен. Поэтому
    проверяющим хватит Python, а Node нужен только чтобы менять интерфейс.
  - В API добавил общий итог по всем договорам, сервер теперь отдаёт и сам
    интерфейс.
